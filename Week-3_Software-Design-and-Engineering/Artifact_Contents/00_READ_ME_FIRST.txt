This folder contains the original CS 320 Contact, Task, and Appointment project and the version I enhanced for the capstone.

01_ORIGINAL_ARTIFACT_UNMODIFIED
    My original CS 320 Java source, tests, and reflection file.

02_ENHANCED_SOFTWARE_DESIGN_ARTIFACT
    The enhanced Maven project. This version combines the three services into one project and includes the validation, copying, exception, update, and testing changes described in my narrative.

03_DOCUMENTATION
    Notes about the changes, design choices, tests, references, and course outcomes.

04_EVIDENCE
    Saved test/verification output and scripts used while checking the final project.

The original and enhanced folders are separate so they can be compared directly.

To run the Maven tests, open the cs320-service-suite folder inside the enhanced artifact and run:
    mvn clean test
