 CS 360 – Mobile Architecture and Programming Portfolio Reflection

Madison Parker
 Project Summary

For this course, I developed a mobile weight-tracking application for Android using Android Studio and Java. The goal of the application was to provide users with a simple way to create an account, securely log in, record their weight, update or delete entries, and review their progress over time. The app was designed to address the need for an easy-to-use health tracking tool that allows users to organize and manage their weight records without unnecessary complexity.

 User-Centered Design

To support user needs, I designed several screens including a login screen, account creation screen, weight management screen, and settings screen for SMS notifications. These screens allowed users to complete one task at a time, making navigation straightforward and reducing confusion. I used clear labels, organized layouts, and consistent buttons throughout the application so users could quickly understand how to interact with the app. By focusing on simplicity and keeping related features together, the interface remained user-friendly and accessible.

 Development Process

I approached development by breaking the project into smaller milestones. I first created the user interface layouts, then built the SQLite database, followed by implementing login functionality and CRUD (Create, Read, Update, Delete) operations for weight entries. Finally, I added navigation and supporting features such as the SMS settings page. Developing one feature at a time allowed me to identify problems early and made debugging much easier. This structured development process is a strategy I will continue using on future software projects because it keeps large applications manageable.

 Testing

Throughout development, I continuously tested each feature as it was completed. I verified that users could successfully create accounts, log in, insert new records, update existing records, delete records, and retrieve stored information from the database. I also tested navigation between activities and validated user input to reduce errors. Testing throughout development was important because it helped reveal issues immediately rather than waiting until the project was complete, making them much easier to fix.

 Challenges and Innovation

One of the biggest challenges was integrating the database with the application's user interface while ensuring each button correctly performed its intended operation. I also had to troubleshoot navigation between activities and verify that user data was stored and retrieved correctly from SQLite. Working through these issues strengthened my debugging skills and gave me a better understanding of how the front end and back end of a mobile application work together.

 Demonstration of Knowledge and Skills

The area where I believe I demonstrated the strongest understanding was implementing the application's database functionality. Successfully creating user authentication along with complete CRUD operations showed my ability to connect a user interface with persistent data storage. Completing this project also strengthened my knowledge of Android Studio, Java programming, SQLite databases, activity navigation, user-centered design, and the overall mobile application development lifecycle.
