# Module One Plan Change

## Why I changed the Category One project

In my original Module One plan, I chose the CS 250 SNHU Travel planning material for Software Design and Engineering. That material was useful for showing user stories, acceptance criteria, Agile planning, and communication, but it did not contain enough source code for the kind of code enhancement required later in the capstone.

After reviewing my earlier projects, I chose the CS 320 Contact, Task, and Appointment services for the Category One code work. The original CS 320 project already had working Java classes and tests, so I could show a real before-and-after improvement instead of building a different application from scratch.

The final use of the projects is:

- **CS 250:** planning, Agile, requirements, and collaboration examples.
- **CS 320:** Software Design and Engineering, followed by the Algorithms and Data Structures enhancement.
- **CS 360:** Database enhancement using the Android Weight Tracker.

## How the plan changed

| Original plan | What I did in the capstone |
| --- | --- |
| Use CS 250 for Category One | Kept CS 250 as planning context and used CS 320 for the source-code enhancement |
| Improve search and sorting in CS 320 | Added the search, filtering, sorting, and complexity work in Week 4 |
| Improve the CS 360 database | Redesigned the Weight Tracker database in Week 5 |

I kept the original Module One document in the repository so the change in direction can be seen alongside the later work.
