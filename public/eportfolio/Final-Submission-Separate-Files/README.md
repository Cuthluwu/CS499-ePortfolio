# Separate CS 499 Code Downloads

These ZIP files separate the original and enhanced source code for each capstone category.

- Software Design: original CS 320 code and enhanced Java service suite
- Algorithms: original CS 320 code, the Week 3 design baseline, and the Week 4 algorithms enhancement
- Databases: original CS 360 Android project and enhanced Android/SQLite project

The combined milestone artifact ZIPs remain the best files to use when Brightspace provides one artifact upload field per category because those packages also include documentation and verification evidence. These smaller ZIPs are available when the instructor wants the original and enhanced code uploaded separately.
