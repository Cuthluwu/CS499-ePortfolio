How I evaluate my work

Reliability
Failure should not leave partial state or destroy existing data.
Clarity
Another person should be able to find the requirement, the code, and the test without guessing.
Privacy
Access belongs to the authenticated owner, not merely to a hidden screen.
Respect
Interfaces and technical claims should be accessible, neutral, and honest.
